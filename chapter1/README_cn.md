# 第一部分 宇宙的起源

## 第一章 宇宙第一定律 动量守恒定律

---

### 1. 宇宙起源问题的坦诚开场

宇宙的起源，到底是怎样的？茫茫宇宙，我们要从哪里开始？

坦诚地说，无法知道。

奇点是什么？不知道。奇点之前是什么？不知道。暴胀怎么触发的？不知道。暴胀怎么停下的？不知道。夸克-胶子等离子体到底存不存在？不知道。从奇点到星云的演化曲线能不能画出来？不能。关于宇宙的起源，我们有太多不知道。每一个不知道都是一个坑，掉进去就爬不出来。

大爆炸理论试图解决宇宙起源问题。它给出了一个完整的答案——宇宙从奇点开始，经历暴胀、原初核合成、光子退耦，最终形成星系和恒星。这套答案被写进了教科书，被无数人接受，被当作标准模型。

### 2. GULP对大爆炸理论的三条质疑

但GULP不认这笔账。它提出了三条具体的质疑。

第一条，演化动力学缺失。大爆炸理论描述了宇宙膨胀的过程，却没有解释驱动膨胀的力从哪里来。暴胀为什么开始？为什么结束？引擎在哪里？

第二条，演化曲线断裂。从奇点到星云，中间有太多环节缺乏连续的观测数据，时间轴上到处都是缺口。

第三条，虚拟节点被当作确定性节点使用。夸克没有被直接观测到，宇宙早期的夸克-胶子等离子体更是一个推断中的状态。把推断当作事实，再在这个事实上搭建更早期的宇宙模型，这是用假设证明假设。

我们得承认，这些质疑确实指出了大爆炸理论的软肋。奇点物理规律失效，暴胀机制缺乏直接证据，从奇点到星云的演化曲线布满了断裂。现有的证据链太少了，少到我们无法把那段历史完整地拼出来。也许有一天，新的观测数据能填补这些空白。但在那之前，这些质疑是成立的。

### 3. 解决提出问题的人——GULP

问题还在那里，目前无法解决，那我们就来解决提出问题的GULP。GULP本身是不是存在问题？它的唯一核心原理是零Bug度，到底有什么物理学依据？

零Bug度的意思很简单：一个系统，在变化中能不能保持自身的结构和一致性。能，就继续存在。不能，就瓦解。它不是“完美无缺”，也不是“静止不变”。它指的是动态稳定——在持续受到干扰的情况下，系统通过内部调节维持自身的连续性。

那么，物理学中有什么定律符合这个描述？什么定律保证了一个系统在变化中不会自发崩溃？零Bug度在物理世界中的第一条对应，就是动量守恒定律。

### 4. 动量守恒定律对GULP的验证

动量守恒定律是这样描述的：一个系统不受外力或所受外力之和为零时，系统的总动量保持不变。

它的公式是：

p = mv

p是动量，m是质量，v是速度。动量是矢量，有大小也有方向。对于一个封闭系统，碰撞前的总动量等于碰撞后的总动量：

m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'

无论系统内部发生了什么——碰撞、爆炸、重组——总动量永远是一个定值。系统可以千变万化，但变化被约束在一个不变的框架里。这就是动态稳定最根本的物理体现。

这条定律不是谁拍脑袋想出来的。笛卡尔最早提出运动量守恒的概念，惠更斯发现动量必须考虑方向，牛顿第三定律——作用力与反作用力大小相等、方向相反——直接蕴含了动量守恒。两个物体碰撞，A对B施加一个力，B对A施加一个大小相等、方向相反的力，作用时间相同，A损失的动量恰好等于B获得的动量。总动量不变。

但最根本的证明来自诺特定理。1918年，埃米·诺特证明：每一个连续对称性都对应一个守恒律。空间平移对称性——物理规律在任何位置都一样——对应动量守恒。这意味着动量守恒不是实验上碰巧发现的经验规律，而是时空结构本身的数学必然。只要空间是对称的，动量就必须守恒。这不是一条可以被推翻的规律，而是一条不可能被违反的规律。

诺特定理要求对称性是连续的。空间平移可以取任意小的量，拉格朗日量对坐标的偏导数必须存在，欧拉-拉格朗日方程才能成立，守恒量的推导才能完成。连续性、可积性、可导性，三者共同构成了诺特定理的数学基础。

这同时也证明了一件至关重要的事：演化曲线必须是连续的。系统从一个状态演化到下一个状态，中间不存在断裂。如果演化曲线出现跳跃或断点，意味着系统在某个时刻违反了动力学方程，而动力学方程是由连续对称性推导出来的。动量守恒强制要求演化曲线连续——不是GULP要求的，是时空结构本身要求的。

反过来说，如果演化曲线出现了跳跃，系统从t₁直接跳到t₂，跳过了中间的状态，那p₁是怎么变成p₂的？中间缺失的那段时间里，是什么力作用了多少时间，产生了多少冲量，全是空白。动量变化没有原因，动量守恒就被违反了。跳跃不是“未知”，是“不可能”。

---

到这里，动量守恒定律同时验证了GULP的两个核心概念：演化曲线的连续性和零Bug度。

演化曲线连续，因为动量守恒不允许时间轴上出现断裂。零Bug度成立，因为动量守恒为系统提供了一个不管内部怎么折腾都不会散架的骨架——总动量永远是一个定值，系统在变化中不会自发崩溃。零Bug度不是哲学空想，它在动量守恒里找到了物理实体。演化曲线连续性不是方法论偏好，它在动量守恒里找到了数学强制。一条定律，同时击中了两个概念。

不仅如此，动量守恒还直接要求演化动力学的存在。系统当前的动量是一个定值。如果下一刻动量改变了，那只有一个可能：有外力介入了。外力乘以作用时间，就是冲量，冲量改变了动量。动量变化必须有一个来源，这个来源就是力。变化了多少，就能倒推出作用力的大小和方向。引擎在哪里，为什么加速，为什么减速——每一步都必须有答案。没有无来由的变速，没有无引擎的演化。

GULP的零Bug度在动量守恒里找到了物理实体。而演化动力学的问题，我们留给下一章的光速不变原理。
