# 第二章 宇宙第二定律 光速不变原理

---

### 1. 一个问题

第一章我们解决了零Bug度的物理依据。动量守恒定律证明了，一个系统在变化中保持内部一致性，不是哲学空想，是物理必然。

但GULP还有一条质疑没有解决：演化动力学。大爆炸理论描述了宇宙膨胀的过程，却没有解释驱动膨胀的力从哪里来。GULP同样必须回答这个问题——是什么驱动了系统的变化？

要回答这个问题，我们需要请出第二条定律。

### 2. 光速不变原理

光速不变原理的表述是：真空中的光速在所有惯性参考系中都是恒定不变的，与光源和观察者的相对运动无关。

这个恒定值精确地等于：

c = 299,792,458 m/s

约每秒三十万公里。

这个原理包含两层含义。第一，光速是一个常数，不随参考系改变。你站在地面上测量光速，结果是c。你在一艘以接近光速飞行的飞船上测量光速，结果还是c。你朝着光源飞奔，或者背离光源远行，光速始终是c。第二，光速与光源的运动无关。光源静止，发出的光速是c。光源以接近光速运动，发出的光速仍然是c。光一旦发出，就脱离光源独立存在，它的速度不再受光源运动的影响。

这与日常经验完全违背。你在高铁上向前扔一个球，球相对于地面的速度等于高铁速度加上你扔球的速度。这是伽利略速度叠加法则。但如果你在高铁上向前打开手电筒，光相对于地面的速度不是光速加上高铁速度，它还是光速。速度叠加法则在光这里失效了。

### 3. 迈克尔逊-莫雷实验

光速不变不是理论推导的结果，是实验测出来的。

1887年，迈克尔逊和莫雷设计了一套干涉仪，用来测量地球在以太中运动对光速的影响。当时的物理学界普遍认为，光是靠一种叫“以太”的介质传播的，就像声音靠空气传播。如果地球在以太中运动，应该能测到“以太风”——顺着以太风方向的光速应该更快，逆着以太风方向的光速应该更慢。

他们用半镀银镜将一束光分成两束，一束沿着地球运动方向，一束垂直于地球运动方向，两束光各自反射后重新汇合，产生干涉条纹。如果两条路径的光速不同，干涉条纹应该发生偏移。为了提高精度，他们把整个仪器放在水银池上旋转，分别在白天和夜晚、不同季节反复测量。

结果为零。

干涉条纹始终不变。无论怎么旋转仪器，无论什么时间测量，两条路径的光速完全相等。以太不存在。光速不变。

这个实验是物理学史上最著名的“失败实验”之一——它没有测到预期的结果，但它的零结果比任何正结果都重要。它直接动摇了牛顿力学的绝对时空观，催生了狭义相对论。而且它极其可靠，到今天你还可以在任何精密光学实验室里重复它。

### 4. 光速的物理意义

光速不变不是一个孤立的规律。它直接导致了时空结构的根本性重构。

在牛顿力学中，时间和空间是独立的、绝对的。时间均匀流逝，空间固定不变。但光速不变强制要求时间和空间必须关联。如果光速在任何参考系中都不变，那么不同参考系中的时间和空间就必须彼此协调，以保证光速这个比值永远不变。

这就是狭义相对论的核心。同时性是相对的，时间会膨胀，长度会收缩。这些效应不是数学游戏，它们都在实验中被反复验证。GPS卫星必须校准相对论效应，否则定位误差每天累积十公里。粒子加速器中的不稳定粒子，寿命因接近光速而显著延长，精确符合相对论预言。

光速不仅是光的速度。它是时空本身的几何属性。它是因果律的边界。

任何信号、任何能量、任何信息的传递速度都不能超过光速。这不是技术限制，是逻辑限制。如果一个信号超光速，就意味着在某些参考系中，结果会出现在原因之前。因果倒置，逻辑崩溃。

### 5. 光速不变与演化曲线

光速不变对GULP的演化曲线提出了一个强制性的约束。

演化曲线要求系统的状态变化在时间轴上保持连续。光速不变为这个连续性给出了物理上限：任何两个时刻之间的状态变化，其信息传递速度不能超过光速。如果系统中A点的变化要影响到B点，这个影响必须以不高于光速的速度传播。

这意味着演化曲线不仅是连续的，而且是因果连续的。t1时刻的状态通过有限速度传播到t2时刻，中间没有跳跃，没有瞬移，没有超距作用。

这对大爆炸理论的空间膨胀提出了一个无法回避的问题。如果空间膨胀的速度超过光速——暴胀期间确实如此——那么宇宙不同区域之间的因果联系就被切断了。一个区域发生的事件无法以任何方式影响到另一个区域。这样的膨胀不是任何已知的力驱动的——因为力的传播速度上限就是光速。演化动力学在这里遇到了不可逾越的边界。

### 6. 光速不变与零Bug度

光速不变同时也强化了零Bug度的物理基础。

零Bug度要求系统在变化中保持内部一致性。光速不变为这个要求提供了时间窗口。因为信号传播有上限，系统内部的扰动不会瞬间传遍全局。一个局部的不一致，只会以光速向外扩散。系统有反应时间，可以逐层调节，逐层吸收扰动，在局部解决问题，而不至于瞬间全局崩溃。

如果光速是无限的——就像牛顿力学假设的那样——那么任何一个局部扰动都会立刻影响到整个宇宙。一颗超新星爆发，全宇宙同时感受到它的引力变化。一个局部的不一致瞬间变成全局的不一致，零Bug度在这种宇宙里根本无法维持。

光速不变让扰动有传播时间，让系统有调节空间。它是零Bug度在物理世界中的第二道保障。

---

光速不变原理和动量守恒定律，两条定律加在一起，已经为GULP奠定了物理基础。动量守恒保证了演化曲线的连续性和零Bug度的第一道屏障。光速不变保证了因果结构的完整性和零Bug度的第二道保障。

但还有一个问题悬在半空：演化动力学。是什么驱动了系统的变化？两条定律给出了约束，但没有给出答案。这个问题，我们留给下一章。
