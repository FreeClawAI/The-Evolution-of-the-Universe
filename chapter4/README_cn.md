# 第四章 洛伦兹变换

## 1. 一个问题

前面的章节，我们讨论了相对性原理和光速不变原理。

相对性原理告诉我们：所有惯性参考系中的物理规律都是相同的。没有任何一个惯性参考系是特殊的。
光速不变原理告诉我们：真空中的光速在所有惯性参考系中都相同，恒定为：c = 299,792,458 米/秒。

这两个原理结合起来，产生了一个必须解决的问题：
如果不同观察者处于不同的运动状态，但他们测量到的光速完全一样，那么他们测量到的时间和空间，应该如何转换？

在牛顿力学中，这个问题很简单。
假设小明站在地面，小红坐在一艘以速度v运动的飞船上。

牛顿认为：
空间可以直接相加。如果小明测量一个物体的位置为s，小红测量的位置为s'，那么：
```
s' = s - vt
```

时间则完全独立：
```
t' = t
```

这就是伽利略变换。但是光速不变原理告诉我们，这套变换无法成立。

因为按照伽利略变换，速度应该满足简单相加关系。
如果飞船速度为v，飞船内发出的光速度为c，那么地面观察者应该测量到：
```
c' = c + v
```
也就是说，不同运动状态的观察者应该测量到不同的光速。

但实验告诉我们，无论光源如何运动，无论观察者如何运动，测量到的光速永远是：c，
因此，空间和时间之间必须进行重新调整。

宇宙需要一种新的坐标转换规则。

这个规则，就是洛伦兹变换。

---

# 2. 两个参考系中的光传播

为了推导洛伦兹变换，我们考虑两个惯性参考系。

定义：
小明所在的参考系为：S系
小红所在的飞船参考系为：S'系

小红的飞船相对于小明，以速度v沿x方向匀速运动。两个参考系在某一时刻重合：
```
t = 0
```

此时：
```
s = 0
s' = 0
```

两个人同时把自己的时钟调整为0。

注意：
此时光还没有发出。
接下来，两人在自己的参考系中分别进行光速实验。

## 小明的测量

小明认为自己静止。他打开手电筒，光沿x方向传播。经过时间t，小明测量光传播距离为s。
根据光速定义：
```
s = ct
```

两边平方：
```
s² = c²t²
```

整理：
```
s² - c²t² = 0
```

## 小红的测量

小红在飞船中。在她自己的参考系里，她认为自己是静止的。
她同样打开手电筒，让光沿飞船前进方向传播。经过时间t'，她测量光传播距离为s'。

由于光速不变：
```
s' = ct'
```

两边平方：
```
s'² = c²t'²
```

整理：
```
s'² - c²t'² = 0
```

注意：
这里不是两个人测量同一束光。
小明测量的是自己参考系中的一次光传播过程。
小红测量的是自己参考系中的一次光传播过程。

两次实验条件相同，但发生在不同参考系中。因为光速在两个参考系中都是c，所以：
```
s² - c²t² = s'² - c²t'²
```
这个量在不同惯性参考系中保持不变。它叫做：**时空间隔。**

更严格地说，对于光的传播过程：

s² - c²t² = 0

这是时空间隔为零的特殊情况。

对于普通事件，时空间隔一般不等于零。

洛伦兹变换，就是寻找一种坐标变换，使这个更普遍的时空间隔保持不变。

---

# 3. 两个参考系如何转换

现在的问题是：
已知小明测量的数据：
```
(s,t)
```

如何计算小红测量的数据：
```
(s',t')
```

反过来也一样。因为两个参考系之间只有一个相对速度v。所以转换关系只能由v决定。

## 为什么是线性关系？

假设两个惯性参考系之间的转换包含：s²，t²等非线性项。
那么，一个在小明看来做匀速直线运动的物体，在小红看来可能变成加速运动。
这意味着惯性定律在不同参考系中不再成立。

但是相对性原理要求：
所有惯性参考系中的物理规律完全相同。因此，两个惯性参考系之间的转换必须保持惯性运动不变。最简单且唯一满足这一要求的形式，就是线性变换。

因此设：

```
s' = As + Bt       (1)
t' = Cs + Dt       (2)
```

其中：
A、B、C、D是四个未知常数。它们只与相对速度v有关。

---

# 4. 四个条件求解四个系数

现在的问题是：如何确定A、B、C、D？需要四个独立条件。

## 第一组条件：参考系原点的运动

在实验开始时：
```
t = 0
```

小明和小红的位置重合。两人的坐标原点同时设为：
```
s = 0
s' = 0
```

此时光还没有发出。随后，小红乘坐飞船以速度v运动。

从小明的参考系看，小红的坐标原点随着飞船移动：
```
s = vt
```

而在小红自己的参考系中，她始终位于自己的坐标原点：
```
s' = 0
```

因此，把：
```
s' = 0
s = vt
```

代入(1)式s' = As + Bt，得到：
```
0 = A(vt) + Bt
```

所以：
```
B = -Av
```

最后，(1)式 s' = As + Bt 变成：
```
s' = As + (-Av)t = A(s - vt)       (3)
```
---

## 第二组条件：光速不变

考虑一束沿x方向传播的光。在小明参考系：
```
s = ct
```

在小红参考系：
```
s' = ct'
```

代入(3)式 s' = A(s - vt) 得到：
```
s' = ct' = A(ct - vt)
```

提取t：
```
ct' = At(c - v)
```

所以：
```
t' = At(c - v) / c
```

另一方面：
```
s = ct
```

代入(2)式 t' = Cs + Dt 得到：
```
t' = Cct + Dt
```

整理：
```
t' = t(Cc + D)
```

两个表达式相等：
```
At(c - v) / c = t(Cc + D)
```

约去t：
```
A(c - v) / c = Cc + D
```

得到第二个约束。即：
```
A(1 - v/c) = Cc + D
```

---

## 第三组条件：相对性原理——逆变换必须具有相同形式

相对性原理要求：所有惯性参考系都是等价的。
因此，小明看小红的运动，与小红看小明的运动，必须遵循相同的物理规律。

对于小明来说，小红相对于他的速度是v，
那么对于小红来说，小明相对于她的速度就是-v。

因此，两个参考系之间的转换必须具有对称性。

正变换，即(3)式：
```
s' = A(s - vt)
```

反过来：
```
s = A(s' + vt')
```

也就是说，从S系到S'系，再从S'系返回S系，必须恢复原来的坐标。

现在从(3)式 s' = A(s - vt) 可以得到：
```
s'/A = s - vt
s = s'/A + vt
```

代入：
```
t' = Cs + Dt
```

得到：
```
t' = C(s'/A + vt) + Dt
```

展开：
```
t'= Cs'/A + (Cv + D)t
```

因此：
```
t = (t' - Cs'/A) / (Cv + D)
```

代回：
```
s = s'/A + vt
```

得到：
```
s = s'/A + v(t' - Cs'/A) / (Cv + D)
```

整理：
```
s = s'[1/A - vC/(A(Cv + D))] + vt'/(Cv + D)
```

现在考虑小明自己的原点。

在小明参考系：
```
s = 0
```

这个位置在小红看来应该以速度-v运动。

因此：
```
s' = -vt'
```

代入：
```
s = s'[1/A - vC/(A(Cv + D))] + vt'/(Cv + D)
```

得到：
```
0 = (-vt')[1/A - vC/(A(Cv + D))] + vt'/(Cv + D)
```

两边除以vt'：
```
0 = -[1/A - vC/(A(Cv + D))] + 1/(Cv + D)
```

整理：
```
1/A - vC/(A(Cv + D)) = 1/(Cv + D)
```

两边乘以 A(Cv + D) 得到：
```
Cv + D - vC = A
```

因为：
```
Cv = vC
```

所以：
```
D = A
```

得到第三个条件：
```
D = A
```

---

## 第四组条件：正反变换对称

由于两个参考系完全等价。从小红返回小明时，空间坐标前面的系数也必须保持一致。
也就是说：逆变换中的空间系数应该与正变换中的A相同。

因此：

```
1/A - vC/(A(Cv + D)) = A
```

两边乘以A：
```
1 - vC/(Cv + D) = A²
```

利用：
```
D = A
```

得到：
```
1 - vC/(Cv + A) = A²
```

移项：
```
vC/(Cv + A) = 1 - A²
```

两边乘：
```
Cv + A
```

得到：

```
vC = (1 - A²)(Cv + A)
```

展开：
```
vC = (1 - A²)Cv + (1 - A²)A
```

移项：
```
vC - (1 - A²)Cv = (1 - A²)A
```

左边提取：
```
vC[1 - (1 - A²)] = (1 - A²)A
```

所以：
```
vCA² = (1 - A²)A
```

约去A：
```
vCA = 1 - A²
```

得到：
```
C = (1 - A²) / (Av)
```

这就是第四个条件。

---

# 5. 求解四个系数

现在我们有：

第一个条件：
```
B = -Av
```

第二个条件：
```
A(1 - v/c) = Cc + D
```

第三个条件：
```
D = A
```

第四个条件：
```
C = (1 - A²) / (Av)
```

把：
```
D = A
```

代入第二个条件：
```
A(1 - v/c) = Cc + A
```

两边减去A：
```
-Av/c = Cc
```

所以：
```
C = -Av/c²
```

现在：
```
C = (1 - A²) / (Av)
```

和：
```
C = -Av/c²
```

相等：
```
(1 - A²)/(Av) = -Av/c²
```

两边乘以：
```
Av
```

得到：
```
1-A² = -A²v²/c²
```

整理：
```
1 = A² - A²v²/c²
```

提取：
```
1 = A²(1 - v²/c²)
```

因此：
```
A² = 1 / (1 - v²/c²)
```

因为速度方向保持一致，取正值：
```
A = 1 / √(1-v²/c²)
```

定义：
```
γ = 1 / √(1-v²/c²)
```

四个系数全部确定：

```
A = γ
B = -γv
C = -γv/c²
D = γ
```

---

# 6. 洛伦兹变换

将四个系数代入：

```
s' = As + Bt
```

得到：
```
s' = γ(s - vt)
```

时间：
```
t' = Cs + Dt
```

得到：
```
t' = γ(t - vs/c²)
```

最终：
```
s' = γ(s - vt)
t' = γ(t - vs/c²)
```

其中：
```
γ = 1 / √(1-v²/c²)
```
这就是洛伦兹变换。

洛伦兹变换描述了：
不同惯性参考系之间，空间坐标和时间坐标如何转换。
它不是人为规定的一套公式，而是在光速不变和相对性原理共同约束下，数学上必然得到的结果。

---

# 7. 洛伦兹因子 γ

洛伦兹因子：

```
γ = 1 / √(1-v²/c²)
```

它描述了高速运动下时空变化的程度。

当 v = 0 时：γ = 1 洛伦兹变换退化为：
```
s' = s
t' = t
```

这就是经典力学中的情况。

当速度增加 v → c 时：
```
1 - v²/c² → 0
```

因此：γ → ∞

这说明：

速度越接近光速，时间和空间的变化越明显。

任何具有静质量的物体，都无法达到光速。

因为达到光速需要无限大的能量。

光速因此成为宇宙中信息和物质运动的极限。

---

# 8. 从洛伦兹变换进入狭义相对论

洛伦兹变换解决了一个困扰物理学的问题：为什么不同运动状态的观察者，仍然能够测量到相同的光速？

答案是：时间和空间并不是牛顿力学中绝对不变的背景。

为了保持光速不变，不同观察者测量到的时间和空间必须发生相应调整。

但是，洛伦兹变换本身只是描述了不同参考系之间的数学关系。

它告诉我们：空间如何转换，时间如何转换。

但它还没有告诉我们：这种转换意味着什么？时间是否真的会变慢？

空间是否真的会缩短？

质量、能量和时空之间有什么更深层的关系？

这些问题，将在下一章中展开。
