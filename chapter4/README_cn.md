# 第四章 洛伦兹变换

## 1. 一个问题

前面的章节，我们讨论了相对性原理和光速不变原理。

相对性原理告诉我们：所有惯性参考系中的物理规律都是相同的。没有任何一个惯性参考系是特殊的。
光速不变原理告诉我们：真空中的光速在所有惯性参考系中都相同，恒定为：c = 299,792,458 米/秒。

这两个原理结合起来，产生了一个必须解决的问题：
如果不同观察者处于不同的运动状态，但他们测量到的光速完全一样，那么他们测量到的时间和空间，应该如何转换？

在牛顿力学中，这个问题很简单。
假设小明站在地面，小红坐在一艘以速度v运动的飞船上。

牛顿认为：
空间可以直接相加。如果小明测量一个物体的位置为s，小红测量的位置为s'，那么：
    s' = s - vt

时间则完全独立：
    t' = t

这就是伽利略变换。但是光速不变原理告诉我们，这套变换无法成立。

因为按照伽利略变换，速度应该满足简单相加关系。
如果飞船速度为v，飞船内发出的光速度为c，那么地面观察者应该测量到：
    c' = c + v

也就是说，不同运动状态的观察者应该测量到不同的光速。

但实验告诉我们，无论光源如何运动，无论观察者如何运动，测量到的光速永远是：c，
因此，空间和时间之间必须进行重新调整。

宇宙需要一种新的坐标转换规则。

这个规则，就是洛伦兹变换。

---

## 2. 两个参考系中的光传播

为了推导洛伦兹变换，我们考虑两个惯性参考系。

定义：
小明所在的参考系为：S系
小红所在的飞船参考系为：S'系

小红的飞船相对于小明，以速度v沿s方向匀速运动。两个参考系在某一时刻重合：
    t = 0

此时：
    s = 0
    s' = 0

两个人同时把自己的时钟调整为0。

接下来，考虑同一束光的传播事件，分别在两个参考系中进行测量。

**小明的测量**

小明认为自己静止。他打开手电筒，光沿s方向传播。经过时间t，小明测量光传播距离为s。根据光速定义：
    s = ct

两边平方并整理：
    s² - c²t² = 0

**小红的测量**

小红在飞船中。在她自己的参考系里，她认为自己是静止的。她测量同一束光的传播过程。经过时间t'，她测量光传播距离为s'。由于光速不变：
    s' = ct'

两边平方并整理：
    s'² - c²t'² = 0

光速不变意味着一个关键条件：同一束光的传播事件，在小明看来满足光传播规律 s = ct，在小红看来也必须满足 s' = ct'。换句话说，光锥结构必须在所有惯性参考系中保持不变。

因此，我们需要寻找一种坐标变换，使光锥条件 s² - c²t² = 0 在所有参考系中都成立。

光锥保持要求时空间隔具有相同形式：

s'² - c²t'² = k(v)(s² - c²t²)

其中k(v)是一个与相对速度v有关的比例因子。k(v)不能改变光锥结构，但初始情况下它允许改变整体尺度。后续通过逆变换存在性、参考系对称性以及低速连续性可以证明 k(v) = 1，因此真正的不变量为 s² - c²t²。对于光传播事件，它等于零；对于普通事件，它一般不等于零。洛伦兹变换的任务，就是使这个时空间隔在所有惯性参考系中保持不变。

---

## 3. 两个参考系如何转换

现在的问题是：
已知小明测量的数据：(s,t)

如何计算小红测量的数据：(s',t')

反过来也一样。在空间方向和单位约定相同的情况下，两个参考系之间唯一的物理参数就是相对速度v。所以转换关系只能由v决定。

## 为什么是线性关系？

惯性参考系的一个基本要求是：在一个惯性系中做匀速直线运动的物体，在另一个惯性系中也必须做匀速直线运动。如果转换关系包含非线性项，例如二次项、高阶项或其他非线性函数，那么匀速直线运动经过转换后一般不再保持直线形式，而会出现随时间变化的速度。因此，在满足惯性系等价、空间时间连续以及原点保持的条件下，最一般且满足这些条件的连续坐标变换形式，就是线性变换。

因此设：
    s' = As + Bt       (1)
    t' = Cs + Dt       (2)

其中：
A、B、C、D是四个未知常数。它们只与相对速度v有关。

---

## 4. 四个条件求解四个系数

现在的问题是：如何确定A、B、C、D？需要四个独立条件。

## 第一组条件：参考系原点的运动

在实验开始时：
    t = 0

小明和小红的位置重合。两人的坐标原点同时设为：
    s = 0
    s' = 0

此时光还没有发出。随后，小红乘坐飞船以速度v运动。

从小明的参考系看，小红的坐标原点随着飞船移动：
    s = vt

而在小红自己的参考系中，她始终位于自己的坐标原点：
    s' = 0

因此，把：
    s' = 0
    s = vt

代入(1)式s' = As + Bt，得到：
    0 = A(vt) + Bt

所以：
    B = -Av

最后，(1)式 s' = As + Bt 变成：
    s' = As + (-Av)t = A(s - vt)       (3)

---

## 第二组条件：光速不变

考虑同一束沿s方向传播的光。在小明参考系：
    s = ct

在小红参考系：
    s' = ct'

代入(3)式 s' = A(s - vt) 得到：
    s' = ct' = A(ct - vt)

提取t：
    ct' = At(c - v)

所以：
    t' = At(c - v) / c

另一方面：
    s = ct

代入(2)式 t' = Cs + Dt 得到：
    t' = Cct + Dt

整理：
    t' = t(Cc + D)

两个表达式相等：
    At(c - v) / c = t(Cc + D)

约去t：
    A(c - v) / c = Cc + D

得到第二个约束。即：
    A(1 - v/c) = Cc + D

---

## 第三组条件：相对性原理与逆变换对称性

现在需要确定时间转换系数。时间转换包含两个未知量C和D，需要利用相对性原理提供额外限制。

相对性原理的核心是：两个惯性参考系没有特殊地位，因此S→S'和S'→S必须由同一种数学结构描述。小明看小红以速度v运动，小红看小明以速度-v运动。因此，从S到S'的变换与从S'到S的逆变换，必须具有相同的结构，只是速度符号相反。这意味着逆变换应该具有形式：

s = A'(s' + vt')

其中A'是逆变换的空间系数。从S系到S'系，再从S'系返回S系，必须恢复原来的坐标。

现在从(3)式 s' = A(s - vt) 可以得到：
    s'/A = s - vt
    s = s'/A + vt

代入：
    t' = Cs + Dt

得到：
    t' = C(s'/A + vt) + Dt

展开：
    t'= Cs'/A + (Cv + D)t

因此：
    t = (t' - Cs'/A) / (Cv + D)

代回：
    s = s'/A + vt

得到：
    s = s'/A + v(t' - Cs'/A) / (Cv + D)

整理：
    s = s'[1/A - vC/(A(Cv + D))] + vt'/(Cv + D)

现在考虑小明自己的原点。

在小明参考系：
    s = 0

在小红参考系中，小明所在的S系原点沿负方向以速度-v运动。

因此：
    s' = -vt'

代入：
    s = s'[1/A - vC/(A(Cv + D))] + vt'/(Cv + D)

得到：
    0 = (-vt')[1/A - vC/(A(Cv + D))] + vt'/(Cv + D)

两边除以vt'：
    0 = -[1/A - vC/(A(Cv + D))] + 1/(Cv + D)

整理：
    1/A - vC/(A(Cv + D)) = 1/(Cv + D)

两边乘以 A(Cv + D) 得到：
    Cv + D - vC = A

因为：
    Cv = vC

所以：
    D = A

得到第三个条件：
    D = A

---

## 第四组条件：空间各向同性

相对性原理要求正变换和逆变换具有相同的函数结构，即 A'(v) = A(-v)。现在需要确定 A(v) 与 A(-v) 的关系。

由于空间不存在特殊方向，物理规律不应该依赖于坐标轴正方向的选择。如果将空间坐标方向反转，s → -s，那么相对速度 v → -v，但物理过程本身没有发生改变。因此，描述空间转换的系数只能依赖速度大小，而不能依赖速度方向：

A(-v) = A(v)

即 A(v) 必须是速度的偶函数。

结合 A'(v) = A(-v)，得到 A'(v) = A(v)。因此，逆变换中的空间系数与正变换中的空间系数相同。

根据空间各向同性，已经证明 A' = A，因此代入逆变换关系：

    1/A - vC/(A(Cv + D)) = A

两边乘以A：
    1 - vC/(Cv + D) = A²

利用：
    D = A

得到：
    1 - vC/(Cv + A) = A²

移项：
    vC/(Cv + A) = 1 - A²

两边乘：
    Cv + A

得到：

   vC = (1 - A²)(Cv + A)

展开：
    vC = (1 - A²)Cv + (1 - A²)A

移项：
    vC - (1 - A²)Cv = (1 - A²)A

左边提取：
    vC[1 - (1 - A²)] = (1 - A²)A

所以：
    vCA² = (1 - A²)A

约去A：
    vCA = 1 - A²

得到：
    C = (1 - A²) / (Av)

这就是第四个条件。

---

## 5. 求解四个系数

现在我们有：

第一个条件：
    B = -Av

第二个条件：
    A(1 - v/c) = Cc + D

第三个条件：
    D = A

第四个条件：
    C = (1 - A²) / (Av)

把：
    D = A

代入第二个条件：
    A(1 - v/c) = Cc + A

两边减去A：
    -Av/c = Cc

所以：
    C = -Av/c²

现在：
    C = (1 - A²) / (Av)

和：
    C = -Av/c²

相等：
    (1 - A²)/(Av) = -Av/c²

两边乘以Av得到：
    1-A² = -A²v²/c²

整理：
    1 = A² - A²v²/c²
 
提取：
    1 = A²(1 - v²/c²)
 
因此：
    A² = 1 / (1 - v²/c²)
 
因为速度方向保持一致，取正值：
    A = 1 / √(1-v²/c²)
 
定义：
    γ = 1 / √(1-v²/c²)
 
四个系数全部确定：
    A = γ
    B = -γv
    C = -γv/c²
    D = γ

---

## 6. 洛伦兹变换

将四个系数代入：
    s' = As + Bt

得到：
    s' = γ(s - vt)

时间：
    t' = Cs + Dt
   
得到：
    t' = γ(t - vs/c²)

最终：
    s' = γ(s - vt)
t' = γ(t - vs/c²)

其中：
    γ = 1 / √(1-v²/c²)
    这就是洛伦兹变换。

洛伦兹变换描述了：
不同惯性参考系之间，空间坐标和时间坐标如何转换。
它不是人为规定的一套公式，而是在光速不变和相对性原理共同约束下，数学上必然得到的结果。

---

### 6.1 为什么空间和时间必须一起改变？

很多读者会有一个疑问：为什么不能只是空间变化，而时间保持不变？

在假设时间保持绝对不变 t' = t 的情况下，考虑只有空间变化：s' = k(s - vt)。那么光在小明参考系s = ct代入后得到s' = kt(c - v)。小红测量光速c' = s'/t' = k(c - v)。除非k随着v变化，否则无法永远等于c。因此，单独改变空间无法保持光速不变。

同样，如果只改变时间t' = kt而空间不变s' = s - vt，也无法保持s'/t' = c。

所以，光速不变要求空间和时间必须作为一个整体共同调整。单独改变空间或者单独改变时间，都无法满足新的约束条件。新的约束迫使宇宙产生新的结构——时空。这就是为什么宇宙不是拥有绝对空间和绝对时间，而是拥有统一的时空。

---

## 7. 洛伦兹因子 γ

洛伦兹因子：
    γ = 1 / √(1-v²/c²)

它描述了高速运动下时空变化的程度。

当 v = 0 时：γ = 1 洛伦兹变换退化为：
    s' = s
    t' = t

这就是经典力学中的情况。在日常低速世界中，我们感受不到相对论效应，因为v远小于c时，γ几乎等于1。经典力学是相对论在低速下的近似，而不是错误。

当速度增加 v → c 时：
    1 - v²/c² → 0

因此：γ → ∞

这说明：

速度越接近光速，时间和空间的变化越明显。

任何具有静质量的物体，都无法达到光速。

因为具有静质量的物体被加速到光速需要无限大的能量。

光速因此成为宇宙中信息和物质运动的极限。

---

## 8. 从洛伦兹变换进入狭义相对论

洛伦兹变换解决了一个关键问题：为什么不同运动状态的观察者，仍然能够测量到相同的光速？

答案是：时间和空间并不是牛顿力学中绝对不变的背景。为了保持光速不变，不同观察者测量到的时间和空间必须发生相应调整。

但是，洛伦兹变换本身只是描述了不同参考系之间的数学关系。它告诉我们空间如何转换、时间如何转换。但它还没有告诉我们：这种转换意味着什么？时间是否真的会变慢？空间是否真的会缩短？质量、能量和时空之间有什么更深层的关系？

这些问题，将在下一章中展开。

---

## 9. 洛伦兹变换的推导总结

整个推导没有预先假设时间膨胀，也没有预先假设长度收缩。我们只使用了四个基本条件：

第一，惯性运动的连续性和匀速直线运动保持性，因此连续坐标转换必须是线性的。

第二，光速不变，因此光锥结构必须保持。

第三，相对性原理，因此正反变换必须具有相同形式。

第四，空间各向同性，因此变换系数不能依赖空间方向。

从四个未知系数A、B、C、D出发，通过四个条件，得到：

A = γ，B = -γv，C = -γv/c²，D = γ

最终得到洛伦兹变换：

s' = γ(s - vt)
t' = γ(t - vs/c²)

洛伦兹变换不是人为设计。它是在已有物理条件下，被逻辑链一步步限定出来的数学结构。

前三章提出了约束——守恒律和对称性要求物理系统的演化受到连续约束，光速不变给出了光锥不变的要求，相对性原理给出了参考系等价的要求，空间各向同性给出了方向无关的要求。第四章在这些约束的共同作用下，推导出了满足条件的时空结构。这正是GULP想表达的演化过程：约束不直接给出答案，但约束限定了可能的形式——当约束足够强时，答案只有一个。

牛顿空间由绝对空间与绝对时间组成。实验发现光速不变，与牛顿体系产生冲突。宇宙没有放弃其中任何一个约束，而是同时接受相对性原理和光速不变。这两个约束共同作用的结果是：绝对空间和绝对时间不再能够独立存在，它们被重新组织成统一的时空结构。

但约束只能告诉我们结构必须满足什么形式，还没有回答为什么宇宙具有这些约束。洛伦兹变换描述了时空的结构，却没有回答这个结构从何而来。演化动力学的问题仍然悬在远处：是什么迫使宇宙从伽利略变换走向洛伦兹变换？这个追问不会停留在第四章，它会一直延伸到更深的物理层。
