# 第五章 狭义相对论

## 1. 一个新的时空观

洛伦兹变换解决了一个困扰物理学的问题：
如果光速对所有观察者都相同，那么不同运动状态下的人，如何转换自己的时间和空间坐标？

答案是：时间和空间必须一起变化。

在牛顿力学中，时间和空间是完全独立的。空间是一个固定舞台。
无论谁运动，时间都按照同样的速度流逝：
    t' = t

一个小时就是一个小时。一个人在地球上度过一年，一个人在高速飞船中度过一年，两个人经历的时间完全相同。

但洛伦兹变换告诉我们：这种绝对时间不存在。

不同观察者测量到的时间间隔可能不同。不同观察者测量到的空间距离也可能不同。
时间和空间不再是两个独立的东西，而是组成一个统一整体：时空。

这就是狭义相对论建立的新世界。

---

# 2. 同时性的相对性

狭义相对论最重要、也是最反直觉的结论之一：

同时发生的事情，对于不同观察者可能不是同时。

我们看一个简单实验。

假设一列高速运动的火车。

火车中间站着小红。

火车前端和后端各有一盏灯。

现在，火车两端同时闪光。

对于站在火车上的小红来说：

两束光距离她一样远。

光速也是一样的。

所以两束光同时到达小红。

她判断：

两端闪光是同时发生的。

但是站在地面的观察者小明看到不同结果。

因为火车正在向前运动。

火车前端正在远离后端。

向前传播的光，需要追赶正在运动的火车前端。

向后传播的光，则迎向正在运动的后端。

虽然两束光速度完全相同，但小明认为：

后方的光先到达。

前方的光后到达。

因此，小明认为：

两端闪光不是同时发生。

这说明：

“同时”不是宇宙绝对属性。

同时性依赖于观察者的运动状态。

---

# 3. 时间膨胀

洛伦兹变换直接推出：

运动中的时间会变慢。

考虑一只光钟。

光钟由两个平行镜子组成。

光在两个镜子之间不断反射。

每一次往返，就是一个时间周期。

假设光钟静止时：

光上下运动。

光走过的距离：

L = ct

其中：

L 是光经过的距离。

t 是钟经历的时间。

现在让光钟高速运动。

对于外部观察者来说：

光不仅上下运动，同时还随着飞船向前运动。

因此，光走过的路线变成了一条斜线。

路线更长。

但是光速永远不变。

仍然是：

c

所以：

光必须花费更多时间完成一次循环。

也就是说：

外部观察者看到：

运动中的时钟走得更慢。

数学表达：

Δt = γΔt'

其中：

Δt 是静止观察者测量的时间。

Δt' 是运动物体自身经历的时间。

γ 是洛伦兹因子：

γ = 1 / √(1-v²/c²)

因为：

γ ≥ 1

所以：

Δt ≥ Δt'

运动速度越快，时间差异越明显。

当速度远小于光速：

v << c

γ接近1。

时间膨胀几乎无法观察。

所以日常生活中牛顿时间仍然成立。

但当速度接近光速：

v → c

γ迅速增加。

时间膨胀变得巨大。

---

# 4. 长度收缩

狭义相对论不仅改变时间，也改变空间。

一个高速运动的物体，在运动方向上的长度会缩短。

这叫：

长度收缩。

假设一艘飞船静止时长度为：

L₀

这是飞船内部乘员测量的长度。

对于地面观察者来说，飞船高速运动。

根据洛伦兹变换：

L = L₀/γ

因为：

γ ≥ 1

所以：

L ≤ L₀

也就是说：

地面观察者看到的飞船长度更短。

速度越接近光速：

γ越大。

长度收缩越明显。

但是必须注意：

长度收缩只发生在运动方向。

飞船的宽度、高度不会变化。

---

# 5. 时间膨胀和长度收缩的本质

时间膨胀和长度收缩并不是两个独立现象。

它们来自同一个原因：

光速不变。

假设时间不改变。

那么高速运动时，光速就会变化。

假设空间不改变。

同样会导致光速变化。

为了保证所有观察者测量到同一个光速：

c

时间和空间必须按照洛伦兹变换重新调整。

所以：

时间膨胀，是时间方向上的调整。

长度收缩，是空间方向上的调整。

它们共同维护一个宇宙不变量：

光速。

---

# 6. 质量和能量

狭义相对论带来了物理学中最著名的公式：

E = mc²

它揭示：

质量和能量不是两个完全不同的东西。

质量是一种高度集中的能量形式。

其中：

E 是能量。

m 是质量。

c 是光速。

由于：

c²

是一个极大的数字。

所以极小的质量，也对应巨大的能量。

例如：

核裂变和核聚变过程中，并不是所有质量都消失。

而是一小部分质量转化为了能量。

这就是核能的物理基础。

---

# 7. 速度叠加的新规则

牛顿力学认为：

速度可以直接相加。

例如：

一辆车速度：

50 km/h

车上一个人向前跑：

10 km/h

地面观察者看到：

60 km/h

但是高速情况下，这个规律失效。

因为如果速度可以简单相加：

一艘接近光速的飞船，再向前发射光。

光速应该超过：

c

但实验告诉我们：

不会。

光速永远是：

c

因此，狭义相对论给出了新的速度转换公式：

u' = (u-v)/(1-uv/c²)

当：

u=c

代入：

u' = (c-v)/(1-v/c)

整理：

u'=c

光速在任何惯性参考系中保持不变。

---

# 8. 狭义相对论的意义

狭义相对论改变了人类对于宇宙的基本认识。

它告诉我们：

第一，时间不是绝对的。

不同观察者经历不同的时间。

第二，空间不是绝对的。

不同观察者测量不同的距离。

第三，时间和空间组成统一的时空。

第四，光速是宇宙中速度的极限。

第五，质量和能量可以相互转换。

牛顿建立的是一个绝对时空中的力学体系。

爱因斯坦建立的是一个相对时空中的物理体系。

但是，狭义相对论仍然有一个限制：

它只适用于惯性参考系。

也就是说：

观察者只能做匀速直线运动。

那么，如果观察者存在加速？

如果存在引力？

如果时空本身会弯曲？

光速不变和相对性原理还能成立吗？

这些问题，将引向物理学的下一次革命。

下一章：

**广义相对论——引力不是一种力，而是时空的几何。**










## 8. 从洛伦兹变换看时间膨胀

洛伦兹变换告诉我们：

```
t' = γ(t - vs/c²)
```
时间不再是绝对不变的量。

它不仅取决于时间坐标t，还取决于空间坐标s。

这意味着：
不同运动状态的观察者，对同一个过程经历的时间可能不同。
现在考虑一个最简单的情况：

小红坐在飞船中。
她在飞船内部同一个位置完成一个过程。

例如：

她的时钟记录两个连续事件：

事件1：
```
x1 = 0
t' = 0
```

事件2：
```
x2' = 0
t' = Δt'
```

因为两个事件发生在小红自己的同一个位置：
```
Δs' = 0
```

使用洛伦兹逆变换：
```
t = γ(t' + vs'/c²)
```

两个事件相减：
```
Δt = γ(Δt' + vΔs'/c²)
```

由于：
```
Δs' = 0
```

所以：

```
Δt = γΔt'
```

因为：

```
γ > 1
```

所以：

```
Δt > Δt'
```

也就是说：
小红自己的时钟测量到的时间间隔更短。
小明看到飞船高速运动，会认为小红的时钟走得更慢。

这就是：

**时间膨胀。**

它不是钟表机械结构的问题。

任何物理过程——原子振动、化学反应、粒子衰变——都会受到同样的影响。

因为改变的不是钟表，而是时间本身。

---

# 9. 从洛伦兹变换看长度收缩

长度收缩同样来自洛伦兹变换。

假设一根杆固定在小红的飞船中。

对于小红来说：

这根杆是静止的。

她测量长度：

```
L₀ = s'₂ - s'₁
```

这个长度叫：

**固有长度。**

现在小明观察飞船。

由于飞船高速运动，小明需要同时测量杆两端的位置。

同时意味着：

```
Δt = 0
```

根据洛伦兹变换：

```
s' = γ(s - vt)
```

对杆的两个端点：

```
s'₁ = γ(s₁ - vt₁)
s'₂ = γ(s₂ - vt₂)
```

两式相减：
```
s'₂ - s'₁ = γ [(s₂-s₁) - v(t₂-t₁)]
```

因为小明同时测量：
```
t₂ = t₁
```

所以：

```
t₂ - t₁ = 0
```

因此：

```
L₀ = γL
```

得到：

```
L = L₀/γ
```

所以：

小明测量到的运动杆长度，比小红测量到的静止长度更短。

这就是：

**长度收缩。**

注意：

长度收缩只发生在运动方向。

垂直运动方向的长度不会发生变化。

---

# 10. 时间膨胀与长度收缩的统一解释

时间膨胀和长度收缩，并不是两个独立的现象。

它们都是同一个事实产生的结果：

**光速必须对所有惯性观察者保持不变。**

如果空间和时间完全按照牛顿力学保持不变：

那么不同速度的观察者必然测量到不同的光速。

为了保护光速这个宇宙常数：

空间和时间必须共同调整。

因此：

高速运动时：

时间间隔增加：

```
Δt = γΔt'
```

空间长度减少：

```
L = L₀/γ
```

它们共同保证：

无论观察者如何运动：

测量得到的光速始终为：c

洛伦兹变换揭示：

时间和空间不是两个完全独立的背景。

它们组成一个统一结构：

**时空。**

---

# 11. 洛伦兹变换的物理意义

洛伦兹变换不是人为设计出来的一组数学公式。

它来自三个基本要求：

第一：

物理规律在所有惯性参考系中相同。

第二：

真空光速在所有惯性参考系中相同。

第三：

惯性运动规律必须保持不变。

这三个条件共同决定：

牛顿的绝对时间和绝对空间无法继续成立。

宇宙必须采用新的时空结构。

洛伦兹变换告诉我们：

不同观察者可以测量不同的时间和距离。

但是，他们对于物理规律的描述必须保持一致。

这就是现代物理学时空观的基础。

---

# 12. 进入狭义相对论

洛伦兹变换解决了一个核心问题：

不同惯性参考系之间，时间和空间如何转换。但它只是狭义相对论的一部分。

爱因斯坦进一步指出：

如果所有惯性参考系中的物理规律完全相同，那么不仅坐标需要转换，整个物理学理论都必须建立在新的时空结构上。

狭义相对论由此建立。

它包含两个核心原则：

第一：

相对性原理。

物理规律在所有惯性参考系中相同。

第二：

光速不变原理。

真空中的光速对所有惯性观察者保持不变。

从这两个原则出发：

时间膨胀出现了。

长度收缩出现了。

质量与能量关系出现了：
```
E = mc²
```

经典力学中的绝对时间、绝对空间，被统一的时空取代。

但是，狭义相对论仍然有一个没有解决的问题：

它只描述了**惯性运动**。

也就是说：

它描述物体如何在没有引力、没有加速度的情况下运动。

但宇宙中真正的大尺度结构——恒星、星系、黑洞——都受到引力影响。

引力如何进入新的时空框架？

加速度和引力之间有什么关系？

时空为什么会弯曲？

这些问题，将进入下一章：**广义相对论。**
