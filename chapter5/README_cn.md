# 第四章 洛伦兹变换

## 1. 一个问题

前面的章节，我们讨论了相对性原理和光速不变原理。

相对性原理告诉我们：所有惯性参考系中的物理规律都是相同的。没有任何一个惯性参考系是特殊的。
光速不变原理告诉我们：真空中的光速在所有惯性参考系中都相同，恒定为：c = 299,792,458 米/秒。

这两个原理结合起来，产生了一个必须解决的问题：
如果不同观察者处于不同的运动状态，但他们测量到的光速完全一样，那么他们测量到的时间和空间，应该如何转换？

在牛顿力学中，这个问题很简单。
假设小明站在地面，小红坐在一艘以速度v运动的飞船上。

牛顿认为：
空间可以直接相加。如果小明测量一个物体的位置为s，小红测量的位置为s'，那么：
```
s' = s - vt
```

时间则完全独立：
```
t' = t
```

这就是伽利略变换。但是光速不变原理告诉我们，这套变换无法成立。

因为按照伽利略变换，如果小红坐在高速飞船上向前打开手电筒。小明测量到的光速应该等于：
```
光速 + 飞船速度
```

也就是：
```
c + v
```

但实验告诉我们，无论光源如何运动，无论观察者如何运动，测量到的光速永远是：c，因此，空间和时间必须进行重新调整。
宇宙需要一种新的坐标转换规则。这个规则，就是洛伦兹变换。

---

# 2. 两个参考系中的光传播

为了推导洛伦兹变换，我们考虑两个惯性参考系。

定义：
小明所在的参考系为：S系
小红所在的飞船参考系为：S'系

小红的飞船相对于小明，以速度v沿x方向匀速运动。两个参考系在某一时刻重合：
```
t = 0
```

此时：
```
s = 0
s' = 0
```

两个人同时把自己的时钟调整为0。然后，两人在自己的参考系中分别进行光速实验。

## 小明的测量

小明认为自己静止。他打开手电筒，光沿x方向传播。经过时间t，小明测量光传播距离为s。
根据光速定义：
```
s = ct
```

两边平方：
```
s² = c²t²
```

整理：
```
s² - c²t² = 0
```

## 小红的测量

小红在飞船中。在她自己的参考系里，她认为自己是静止的。
她同样打开手电筒，让光沿飞船前进方向传播。经过时间t'，她测量光传播距离为s'。

由于光速不变：
```
s' = ct'
```

两边平方：
```
s'² = c²t'²
```

整理：
```
s'² - c²t'² = 0
```

注意：
这里不是两个人测量同一束光。
小明测量的是自己参考系中的一次光传播过程。
小红测量的是自己参考系中的一次光传播过程。

两次实验条件相同，但发生在不同参考系中。因为光速在两个参考系中都是c，所以：
```
s² - c²t² = s'² - c²t'²
```
这个量在不同惯性参考系中保持不变。它叫做：**时空间隔。**

洛伦兹变换，就是寻找一种坐标变换，使这个量保持不变。

---

# 3. 两个参考系如何转换

现在的问题是：
已知小明测量的数据：
```
(s,t)
```

如何计算小红测量的数据：
```
(s',t')
```

反过来也一样。因为两个参考系之间只有一个相对速度v。所以转换关系只能由v决定。

## 为什么是线性关系？

假设两个惯性参考系之间的转换包含：s²，t²等非线性项。
那么，一个在小明看来做匀速直线运动的物体，在小红看来可能变成加速运动。
这意味着惯性定律在不同参考系中不再成立。

但是相对性原理要求：所有惯性参考系中的物理规律完全相同。因此，两个惯性参考系之间的转换必须保持惯性运动不变。最简单且唯一满足这一要求的形式，就是线性变换。

因此设：

```
s' = As + Bt       (1)
t' = Cs + Dt       (2)
```

其中：
A、B、C、D是四个未知常数。它们只与相对速度v有关。

---

# 4. 四个条件求解四个系数

现在的问题是：如何确定A、B、C、D？需要四个独立条件。

## 第一组条件：参考系原点的运动

在实验开始时：
```
t = 0
```

小明和小红的位置重合。两人的坐标原点同时设为：
```
s = 0
s' = 0
```

此时光还没有发出。随后，小红乘坐飞船以速度v运动。

从小明的参考系看，小红的坐标原点随着飞船移动：
```
s = vt
```

而在小红自己的参考系中，她始终位于自己的坐标原点：
```
s '= 0
```

因此，把：
```
s' = 0
s = vt
```

代入(1)式s' = As + Bt，得到：
```
0 = A(vt) + Bt
```

所以：
```
B = -Av
```

最后，(1)式 s' = As + Bt 变成：
```
s' = As + (-Av)t = A(s - vt)       (3)
```
---

## 第二组条件：光速不变

考虑一束沿x方向传播的光。在小明参考系：
```
s = ct
```

在小红参考系：
```
s' = ct'
```

代入(3)式 s' = A(s - vt) 得到：
```
s' = ct' = A(ct - vt)
```

提取t：
```
ct' = At(c - v)
```

所以：
```
t' = At(c - v) / c
```

另一方面：
```
s = ct
```

代入(2)式 t' = Cs + Dt 得到：
```
t' = Cct + Dt
```

整理：
```
t' = t(Cc + D)
```

两个表达式相等：
```
At(c - v) / c = t(Cc + D)
```

约去t：
```
A(c - v) / c = Cc + D
```

得到第二个约束。即：
```
A(1 - v/c) = Cc + D
```

---

## 第三组条件：相对性原理——逆变换必须具有相同形式

物理规律在所有惯性参考系中相同。因此，小红看小明的运动，也应该遵循同样的转换规则。

对于小明来说，小红相对于他的速度是v，
那么对于小红来说，小明相对于她的速度就是-v。

因此，两个参考系之间的转换必须具有对称性。

正变换，即(3)式：
```
s' = A(s - vt)
```

反过来：
```
s = A(s' + vt')
```

也就是说，从S系到S'系，再从S'系返回S系，必须恢复原来的坐标。

现在从(3)式 s' = A(s - vt) 可以得到：
```
s'/A = s - vt
s = s'/A + vt
```

代入：
```
t' = Cs + Dt
```

得到：
```
t' = C(s'/A + vt) + Dt
```

展开：
```
t'= Cs'/A + (Cv + D)t
```

因此：
```
t = (t' - Cs'/A) / (Cv + D)
```

代回：
```
s = s'/A + vt
```

得到：
```
s = s'/A + v(t' - Cs'/A) / (Cv + D)
```

整理：
```
s = s'[1/A - vC/(A(Cv + D))] + vt'/(Cv + D)
```

现在考虑小明自己的原点。

在小明参考系：
```
s = 0
```

这个位置在小红看来应该以速度-v运动。

因此：
```
s' = -vt'
```

代入：
```
s = s'[1/A - vC/(A(Cv + D))] + vt'/(Cv + D)
```

得到：
```
0 = (-vt')[1/A - vC/(A(Cv + D))] + vt'/(Cv + D)
```

两边除以vt'：
```
0 = -[1/A - vC/(A(Cv + D))] + 1/(Cv + D)
```

整理：
```
1/A - vC/(A(Cv + D)) = 1/(Cv + D)
```

两边乘以 A(Cv + D) 得到：
```
Cv + D - vC = A
```

因为：
```
Cv = vC
```

所以：
```
D = A
```

得到第三个条件：
```
D = A
```

---

## 第四组条件：正反变换对称

由于两个参考系完全等价。从小红返回小明时，空间坐标前面的系数也必须保持一致。

因此：

```
1/A - vC/(A(Cv + D)) = A
```

两边乘以A：
```
1 - vC/(Cv + D) = A²
```

利用：
```
D = A
```

得到：
```
1 - vC/(Cv + A) = A²
```

移项：
```
vC/(Cv + A) = 1 - A²
```

两边乘：
```
Cv + A
```

得到：

```
vC = (1 - A²)(Cv + A)
```

展开：
```
vC = (1 - A²)Cv + (1 - A²)A
```

移项：
```
vC - (1 - A²)Cv = (1 - A²)A
```

左边提取：
```
vC[1 - (1 - A²)] = (1 - A²)A
```

所以：
```
vCA² = (1 - A²)A
```

约去A：
```
vCA = 1 - A²
```

得到：
```
C = (1 - A²) / (Av)
```

这就是第四个条件。

---

# 5. 求解四个系数

现在我们有：

第一个条件：
```
B = -Av
```

第二个条件：
```
A(1 - v/c) = Cc + D
```

第三个条件：
```
D = A
```

第四个条件：
```
C = (1 - A²) / (Av)
```

把：
```
D = A
```

代入第二个条件：
```
A(1 - v/c) = Cc + A
```

两边减去A：
```
-Av/c = Cc
```

所以：
```
C = -Av/c²
```

现在：
```
C = (1 - A²) / (Av)
```

和：
```
C = -Av/c²
```

相等：
```
(1 - A²)/(Av) = -Av/c²
```

两边乘以：
```
Av
```

得到：
```
1-A² = -A²v²/c²
```

整理：
```
1 = A² - A²v²/c²
```

提取：
```
1 = A²(1 - v²/c²)
```

因此：
```
A² = 1 / (1 - v²/c²)
```

因为速度方向保持一致，取正值：
```
A = 1 / √(1-v²/c²)
```

定义：
```
γ = 1 / √(1-v²/c²)
```

四个系数全部确定：

```
A = γ
B = -γv
C = -γv/c²
D = γ
```

---

# 6. 洛伦兹变换

将四个系数代入：

```
s' = As + Bt
```

得到：
```
s' = γ(s - vt)
```

时间：
```
t' = Cs + Dt
```

得到：
```
t' = γ(t - vs/c²)
```

最终：
```
s' = γ(s - vt)
t' = γ(t - vs/c²)
```

其中：
```
γ = 1 / √(1-v²/c²)
```
这就是洛伦兹变换。

---

# 7. 洛伦兹因子 γ

洛伦兹因子：

```
γ = 1 / √(1-v²/c²)
```

它描述了高速运动下时空变化的程度。

当：
```
v = 0
```

时：

```
γ = 1
```

洛伦兹变换退化为：

```
s' = s
t' = t
```

这就是经典力学中的情况。

当速度增加：

```
v → c
```

时：

```
1 - v²/c² → 0
```

因此：

```
γ → ∞
```

这说明：

速度越接近光速，时间和空间的变化越明显。

任何具有静质量的物体，都无法达到光速。

因为达到光速需要无限大的能量。

光速因此成为宇宙中信息和物质运动的极限。

---







## 8. 从洛伦兹变换看时间膨胀

洛伦兹变换告诉我们：

```
t' = γ(t - vs/c²)
```
时间不再是绝对不变的量。

它不仅取决于时间坐标t，还取决于空间坐标s。

这意味着：
不同运动状态的观察者，对同一个过程经历的时间可能不同。
现在考虑一个最简单的情况：

小红坐在飞船中。
她在飞船内部同一个位置完成一个过程。

例如：

她的时钟记录两个连续事件：

事件1：
```
x1 = 0
t' = 0
```

事件2：
```
x2' = 0
t' = Δt'
```

因为两个事件发生在小红自己的同一个位置：
```
Δs' = 0
```

使用洛伦兹逆变换：
```
t = γ(t' + vs'/c²)
```

两个事件相减：
```
Δt = γ(Δt' + vΔs'/c²)
```

由于：
```
Δs' = 0
```

所以：

```
Δt = γΔt'
```

因为：

```
γ > 1
```

所以：

```
Δt > Δt'
```

也就是说：
小红自己的时钟测量到的时间间隔更短。
小明看到飞船高速运动，会认为小红的时钟走得更慢。

这就是：

**时间膨胀。**

它不是钟表机械结构的问题。

任何物理过程——原子振动、化学反应、粒子衰变——都会受到同样的影响。

因为改变的不是钟表，而是时间本身。

---

# 9. 从洛伦兹变换看长度收缩

长度收缩同样来自洛伦兹变换。

假设一根杆固定在小红的飞船中。

对于小红来说：

这根杆是静止的。

她测量长度：

```
L₀ = s'₂ - s'₁
```

这个长度叫：

**固有长度。**

现在小明观察飞船。

由于飞船高速运动，小明需要同时测量杆两端的位置。

同时意味着：

```
Δt = 0
```

根据洛伦兹变换：

```
s' = γ(s - vt)
```

对杆的两个端点：

```
s'₁ = γ(s₁ - vt₁)
s'₂ = γ(s₂ - vt₂)
```

两式相减：
```
s'₂ - s'₁ = γ [(s₂-s₁) - v(t₂-t₁)]
```

因为小明同时测量：
```
t₂ = t₁
```

所以：

```
t₂ - t₁ = 0
```

因此：

```
L₀ = γL
```

得到：

```
L = L₀/γ
```

所以：

小明测量到的运动杆长度，比小红测量到的静止长度更短。

这就是：

**长度收缩。**

注意：

长度收缩只发生在运动方向。

垂直运动方向的长度不会发生变化。

---

# 10. 时间膨胀与长度收缩的统一解释

时间膨胀和长度收缩，并不是两个独立的现象。

它们都是同一个事实产生的结果：

**光速必须对所有惯性观察者保持不变。**

如果空间和时间完全按照牛顿力学保持不变：

那么不同速度的观察者必然测量到不同的光速。

为了保护光速这个宇宙常数：

空间和时间必须共同调整。

因此：

高速运动时：

时间间隔增加：

```
Δt = γΔt'
```

空间长度减少：

```
L = L₀/γ
```

它们共同保证：

无论观察者如何运动：

测量得到的光速始终为：c

洛伦兹变换揭示：

时间和空间不是两个完全独立的背景。

它们组成一个统一结构：

**时空。**

---

# 11. 洛伦兹变换的物理意义

洛伦兹变换不是人为设计出来的一组数学公式。

它来自三个基本要求：

第一：

物理规律在所有惯性参考系中相同。

第二：

真空光速在所有惯性参考系中相同。

第三：

惯性运动规律必须保持不变。

这三个条件共同决定：

牛顿的绝对时间和绝对空间无法继续成立。

宇宙必须采用新的时空结构。

洛伦兹变换告诉我们：

不同观察者可以测量不同的时间和距离。

但是，他们对于物理规律的描述必须保持一致。

这就是现代物理学时空观的基础。

---

# 12. 进入狭义相对论

洛伦兹变换解决了一个核心问题：

不同惯性参考系之间，时间和空间如何转换。但它只是狭义相对论的一部分。

爱因斯坦进一步指出：

如果所有惯性参考系中的物理规律完全相同，那么不仅坐标需要转换，整个物理学理论都必须建立在新的时空结构上。

狭义相对论由此建立。

它包含两个核心原则：

第一：

相对性原理。

物理规律在所有惯性参考系中相同。

第二：

光速不变原理。

真空中的光速对所有惯性观察者保持不变。

从这两个原则出发：

时间膨胀出现了。

长度收缩出现了。

质量与能量关系出现了：
```
E = mc²
```

经典力学中的绝对时间、绝对空间，被统一的时空取代。

但是，狭义相对论仍然有一个没有解决的问题：

它只描述了**惯性运动**。

也就是说：

它描述物体如何在没有引力、没有加速度的情况下运动。

但宇宙中真正的大尺度结构——恒星、星系、黑洞——都受到引力影响。

引力如何进入新的时空框架？

加速度和引力之间有什么关系？

时空为什么会弯曲？

这些问题，将进入下一章：**广义相对论。**
